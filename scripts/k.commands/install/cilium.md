# cilium

Installs the pinned Cilium release with kubeProxyReplacement and the gateway API.

## Description

Runs `k install gateway-api`, then `cilium install` at the version pinned in
state.yaml (`cilium.version`) with `ipam.mode=kubernetes`,
`kubeProxyReplacement=true`, gateway API enabled (`gatewayAPI.enabled=true`
with ALPN, app protocol and host networking) and Envoy enabled. Cilium
connects to the Kubernetes API via `k8sServiceHost=localhost` and
`k8sServicePort=7445`, with cgroup host-root `/sys/fs/cgroup` and the
capability sets pinned in the script. Finally waits for all pods to be Ready
with `k wait kubernetes Cilium`.

## Prerequisites

- Cluster reachable via the kubeconfig generated by `k install kubernetes`.
- state.yaml pins `cilium.version`.

## Usage

```
k install cilium
```

## Notes

- Uses the Cilium CLI for the initial install, not Helm.
- Accepts no arguments.
