# gateway-api

Installs the pinned Kubernetes Gateway API standard release.

## Description

Applies the `standard-install.yaml` release for the version pinned in `state.yaml` (`gateway-api.version`) with `kubectl apply --server-side`.

## Prerequisites

- Cluster reachable via the kubeconfig generated by `k install kubernetes`.
- state.yaml pins `gateway-api.version`.

## Usage

```
k install gateway-api
```

## Notes

- Accepts no arguments.
- Pulls the manifest from the kubernetes-sigs/gateway-api GitHub releases.
